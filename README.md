# Minecraft
## What is it?
This project is a recreation of Minecraft in C, using the OpenGL API specification. GLFW and glad are also utilized to provide easy access to OpenGL related functions (interacting with the GPU, rendering images, writing Shaders in GLSL).

## Why is it?
I wanted to spend some time exploring and learning about C and thought a more involved project would be a good starting point. Beyond just improving my understanding of lower-level programming, I have also been exposed to many tools I did not originally anticipate learning about, such as: OpenGL, OpenGL Shading Language (GLSL), GLFW, glad, Vim, and CMake. This project also forces me to critically think about data structures, code efficiency, and how to plan out large projects with often ambiguous goals.
